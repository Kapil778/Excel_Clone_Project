#  Excel Clone

An Excel-inspired spreadsheet application built using **HTML, CSS, and jQuery**. This project replicates the core functionalities of spreadsheet software, allowing users to enter, edit, and organize data in a grid-based interface.

##  Features

*  Editable spreadsheet cells
*  Dynamic row and column support
*  Cell formatting (bold, italic, underline)
*  Change text alignment and styling
*  Copy and paste cell values
*  Formula input and basic calculations
*  Multiple sheet support
*  Real-time updates using jQuery
*  Responsive and intuitive user interface

##  Built With

* HTML5
* CSS3
* JavaScript
* jQuery
